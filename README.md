# Movie App

A Flutter mobile application that displays movie information using REST APIs.

The application retrieves movie data from an external API and presents it through a simple and user-friendly interface.

## Role

Flutter Developer

Independently designed and developed the application.

## Technologies

- Flutter
- Dart
- REST APIs
- API Integration

## Features

- Fetching movie data from REST APIs
- Displaying movie information
- Movie browsing
- API-based data loading

## Project Type

Mobile Application
